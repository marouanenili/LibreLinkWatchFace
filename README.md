## Installation

1. Clonez le dépôt sur votre machine locale :
   ```bash
   git clone https://github.com/votre-utilisateur/liberlinkupWatchFace.git
2. Ouvrez le projet dans votre IDE Android préféré (comme Android Studio).
3. Compilez et installez l'application sur votre smartwatch Android.

## Utilisation

- Une fois l'application installée sur votre montre, sélectionnez `LiberlinkupWatchFace` comme votre cadran de montre (watch face).
- Le niveau de glycémie sera mis à jour automatiquement à intervalles réguliers, en fonction de la configuration de votre appareil.
- La date et l'heure seront affichées en permanence.
